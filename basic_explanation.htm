Starting point

A model with one record

The model has exactly one chunk allocated — slot 42 falls inside chunk 0 (kChunkSize = 4096 slots), so that's the only chunk that exists at all. It holds one live slot; the other 4095 are empty. Model::spine_ (the writer's working copy) and the published Root's spine point at the literal same Chunk object — nothing has diverged yet, so there is nothing to copy.

shared_ptr, untouched by any commit in flight
Step 1

Begin a transaction, call update()

Model::begin() takes a Snapshot of the current Root (v1) as the transaction's base — a pointer copy, no lock. txn.update<Account>(id) then hands back a mutable pointer to a fresh clone of that object. The clone lives entirely outside the spine: not linked into any Chunk, not visible to any Snapshot, not touched by commit_mu_ at all. Its Id is copied verbatim from the original — {42, 1} — because it names the same object; only its field values are free to change, and can change any number of times, in any order, before commit.

Step 2 · inside try_commit(), under commit_mu_

Apply: clone the chunk, not the model

Once try_commit() takes commit_mu_ and confirms nothing else touched id 42 since this transaction's base, apply_update() installs the clone. The old object is retired — marked invisible starting at the next version, not freed — and set_slot(42, new_ptr, gen=1) writes the new pointer in. That call starts with cow(chunk 0): first touch of a chunk in this attempt clones the whole chunk, all 4096 slots, in one memcpy. Model::spine_[0] is repointed at that clone; the original Chunk 0 is left completely alone — still exactly what Root v1 points at.

original chunk — still what Root v1 sees cloned chunk — spine_[0]'s new target
Step 3

Publish: a new Root, mostly borrowed

publish_now() bumps version_ to 2 and builds a fresh Root. r->spine = spine_ copies the vector — one shared_ptr handle per chunk, O(chunks touched), never O(objects). For this model, that's a single pointer: slot 0 now names Chunk 0'. Model::root_ is swapped to r atomically; every Snapshot taken from this point on sees version 2. Root v1 is not modified, not decremented, not touched — it simply keeps existing, held alive by whatever still references version 1: a live Snapshot, or another transaction's still-open base().

Generation only moves on slot reuse, never on an update. If this record were removed instead, and something later allocated slot 42 for a new object, alloc_slot() would read the slot's current generation (1) and mint {42, 2}. A stale Id{42, 1} held by an old reference would then fail slot_lookup's generation check forever, rather than silently resolving to the new occupant — that's invariant 5, and it's the entire reason Id carries a generation at all instead of just an index.

Summary

What copied, what stayed shared

StructureDetail
The object copied Cloned by Transaction::update() the moment it's requested. The published baseline is never mutated (invariant 3); the clone is written freely until commit, then installed.
Chunk 0 copied One memcpy of all 4096 slots, on first touch of that chunk in this commit attempt (cow()). A second write to a different slot in the same chunk, same commit, reuses this clone — no second copy.
Every other chunk shared Untouched shared_ptr<Chunk> entries carry over into the new Root unchanged — not read, not copied. At 1M objects that's roughly 250 chunks sharing structure while one changes.
The spine vector copied Root's spine is a fresh std::vector of handles — cheap, proportional to chunk count (model size ÷ 4096), not to how many objects changed.
Index maps (by_type, by_key, …) shared This update touched no define_keys()/define_fields() field, so every index handle in the new Root is byte-identical to the old one. A field that is indexed would instead copy only the path from that persistent map's root to the changed leaf — same structural-sharing idea, one level down from the spine.
The Root struct copied One small heap allocation per commit (make_shared<Root>()) — a handful of handles, cheap regardless of model size.
Grounded in include/model/model.h (Id, Chunk, Root) and src/model.cpp (Model::cow, Model::set_slot, Model::apply_update, Model::publish_now). Invariants referenced: 3 (published state is immutable), 4 (nothing frees while a reader can still see it), 5 (Id carries a generation).
